# stp-tree-diff

Порівняння двох STEP-файлів (CAD, `.stp`/`.step`) на рівні дерева елементів
збірки: обʼєм і центр ваги кожної деталі, кольоровий HTML-звіт різниць.

## Навіщо

Коли CAD-модель (наприклад, збірка деталей автомобіля/механізму) оновлюється,
хочеться швидко побачити: яка деталь змінила форму (обʼєм), яка перемістилась
(центр ваги), яку додали чи видалили — без ручного відкриття в CAD-системі.

## Встановлення

```bash
pip install -r requirements.txt --break-system-packages
```

Потребує Python 3.10+. Основна залежність — `cadquery` (тягне за собою
`cadquery-ocp`, Python-біндинги OpenCASCADE — саме вони читають геометрію STEP).

## Використання

```bash
python3 cli.py file_a.stp file_b.stp -o report.html
```

Опції:
- `--volume-tol 0.5` — допуск різниці обʼєму в %, нижче якого зміна не
  вважається значущою (за замовчуванням 0.5%)
- `--com-tol 0.1` — допуск зміщення центру ваги в мм (за замовчуванням 0.1 мм)
- `--json` — додатково вивести diff-дерево в JSON у stdout

Відкрий `report.html` у браузері — побачиш дерево деталей з кольоровим
кодуванням:

- 🟢 **match** — деталь не змінилась (в межах допуску)
- 🟠 **changed** — обʼєм і/або центр ваги відрізняються
- 🔵 **added** — деталь є лише у другому файлі
- 🔴 **removed** — деталь є лише у першому файлі

## Тести

```bash
pytest tests/ -v
```

Тести генерують еталонні STEP-файли на льоту (куб + циліндр з відомими
аналітичними обʼємами) і звіряють результат парсингу з формулами
`V = a·b·c` та `V = π·r²·h`.

## Обмеження поточної версії

- Співставлення вузлів між файлами відбувається за назвою деталі на
  кожному рівні дерева; якщо деталі перейменували між ревізіями — вони
  будуть показані як "видалено" + "додано" замість "changed".
- Формат виводу — статичний HTML (без інтерактивного згортання дерева).
